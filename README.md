# Launcher

A home screen for Android. The wallpaper, and a panel for each swipe:
the apps or Recents. No account, no tracking, no ads.

## Install

Download the APK from [Releases](https://github.com/213YaZ786/Launcher/releases)
and install it, then set Launcher as your home app when it asks.
Android 12 or newer.

## Privacy

Everything stays on your phone. The only connection is a check for a new
version on GitHub, which you can turn off in Settings.
